# fints-client-derive

The `#[derive(Segment)]` macro behind [fints-client](https://crates.io/crates/fints-client): it turns a Rust struct into a FinTS 3.0 segment definition with parsing and serialisation. It is an implementation detail of fints-client and is published only because fints-client depends on it; use fints-client instead.
